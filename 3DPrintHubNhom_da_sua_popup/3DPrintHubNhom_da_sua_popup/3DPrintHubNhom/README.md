# 3DPrintHub Marketplace — PHP / MySQL / Laragon

Demo marketplace nhiều gian hàng, gồm Client, Vendor, Admin. Có phân quyền, đăng sản phẩm, duyệt shop, duyệt sản phẩm, giỏ hàng, COD, thanh toán MoMo/QR mô phỏng, quản lý đơn và biểu đồ doanh thu.

**Đọc hướng dẫn:** [`README_HUONG_DAN.md`](README_HUONG_DAN.md)

**Chạy nhanh:** đặt thư mục trong `D:\laragon\www\3DPrintHubDemo`, bật Laragon, import `database/3DPrintHub_DATABASE_ALL_IN_ONE.sql` khi cài mới, truy cập `http://localhost/3DPrintHubDemo/`.

**Cảnh báo:** Chỉ là demo đồ án; không nhận tiền thật.
